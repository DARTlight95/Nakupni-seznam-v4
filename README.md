# Moje recepty

## GitHub Pages
1. Nahraj všechny soubory z této složky do kořene repozitáře.
2. V GitHubu otevři **Settings → Pages**.
3. Nastav **Deploy from a branch**, větev **main**, složku **/(root)**.
4. Otevři adresu `https://UZIVATEL.github.io/REPOZITAR/`.

## iPhone
V Safari otevři adresu GitHub Pages a zvol **Sdílet → Přidat na plochu**.

Data aplikace včetně fotografií se ukládají lokálně v prohlížeči zařízení.
